Формулы
ax² + bx + c = 0
a — коэффициент перед x² (стоит прямо перед иксом в квадрате).
b — коэффициент перед x (стоит перед одиночным иксом).
c — свободный член: число без иксов вообще.
D = b² − 4ac
x = −b ± √D2a  — при D > 0
x = −b2a  — при D = 0
Теорема Виета
ax² + bx + c = 0
x₁ + x₂ = −ba
x₁ · x₂ = ca
Особые случаи
  • D > 0 — два корня.
  • D = 0 — один корень (два совпавших).
  • D < 0 — действительных корней нет.
⚠ В ax²+bx=0 корень x=0 — тоже настоящий корень, его легко потерять.
⚠ В ax²+c=0 при x²>0 корней два: +√N и −√N — потому что и положительное, и отрицательное число в квадрате дают одно и то же N.
⚠ Квадрат отрицательного числа положителен — не теряй знак при возведении b в квадрат.
