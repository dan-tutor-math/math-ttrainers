# Видео: нарезка и загрузка в Cloud.ru

Скрипт `hls-upload.sh` превращает запись доски (mp4) в HLS — три качества,
постер, главы — и кладёт в бакет `mathh-video`. В конце печатает ссылку на
`master.m3u8`, длительность и готовую запись для `video-links.js`.

## Один раз: инструменты

```bash
brew install ffmpeg awscli
```

Скрипт сам проверит, что они есть, и подскажет команду, если чего-то нет.

## Один раз: ключ доступа

Ключ (Key ID + Key Secret) живёт только в файле
`~/.config/mathh-video/credentials`. В репозиторий, в чат и в аргументы
командной строки он не попадает никогда.

1. Консоль Cloud.ru → Object Storage → «Параметры работы с API».
   Там же видны эндпоинт `https://s3.cloud.ru`, регион `ru-central-1` и
   ID тенанта.
2. Создать ключ доступа. Если консоль попросит сервисный аккаунт —
   создать отдельный, например `mathh-video-upload`, и дать ему роль на
   запись в Object Storage (только её: этим ключом нельзя будет трогать
   ничего, кроме хранилища).
3. Консоль покажет Key ID и Key Secret. **Key Secret показывается один
   раз** — сразу перенести в файл (шаг 4), не закрывая окно.
4. В Терминале:

   ```bash
   mkdir -p ~/.config/mathh-video && touch ~/.config/mathh-video/credentials && chmod 600 ~/.config/mathh-video/credentials && open -e ~/.config/mathh-video/credentials
   ```

   В открывшемся TextEdit вставить две строки и сохранить:

   ```
   CLOUDRU_KEY_ID=<Key ID>
   CLOUDRU_KEY_SECRET=<Key Secret>
   ```

Логин для S3 — `<ID тенанта>:<Key ID>` — скрипт собирает сам, ID тенанта
уже записан в нём. Если права у файла не 600, скрипт откажется работать.

## Каждый раз: ролик

```bash
tools/video/hls-upload.sh ~/Movies/шины-разбор.mp4 oge1-5-tire-razbor --chapters ~/Movies/шины-главы.txt
```

- slug — латиница, цифры, дефис. Он же ключ «места остановки» у учеников,
  поэтому у одного видео он не меняется.
- Файл глав (необязательно), по строке на главу:

  ```
  0:00 Задание 1 — ширина шины
  2:15 Задание 2 — высота боковины
  5:40 Задания 3–5 — диаметр колеса
  ```

- `--no-upload` — только нарезать, ничего не отправлять.
- Нарезка лежит в `~/Movies/mathh-video/<slug>/<дата-время>/`, не в
  репозитории. Каждая загрузка — новая папка в бакете, поэтому перезалив
  ролика = новая ссылка в `video-links.js`.

Вывод скрипта вставить в `videos` в `video-links.js` (поправить `title`,
`kind`), привязку — в `links`, запушить.
