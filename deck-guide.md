# Гайд: HTML-презентации для импорта в доски Mathh

Этот гайд — для преподавателя и для нейросети, которая будет делать презентацию. Как пользоваться: скопируйте гайд целиком в чат с нейросетью (ChatGPT, Claude, DeepSeek, Алиса — любая) и ниже напишите, какая презентация нужна: тема, класс, сколько слайдов, что на них. Готовый файл .html откройте в презентации на доске: кнопка «Импорт» → «HTML».

Дизайн — любой: цвета, шрифты, фон, стиль выбирает преподаватель. Гайд задаёт только разметку — где слайды, где служебные кнопки, где заметки, — чтобы импорт понял файл без ошибок.

Импорт умеет два вида переноса:

- «Слайды картинками» — каждый слайд переносится снимком, точно как в браузере. Поверх можно писать и рисовать, но сам слайд не правится.
- «Полностью» — текст, картинки, формулы, таблицы и простые фигуры становятся объектами доски: их можно двигать и править. Всё, что доска не умеет (тени, градиенты, узоры), остаётся неподвижной подложкой.

## Для нейросети: прежде чем начать

Если преподаватель не сказал сам, коротко спроси его о трёх вещах и предложи вариант по умолчанию:

1. Как переносить: «картинками» (можно любое оформление) или «полностью» (оформление проще, зато всё правится). По умолчанию — «полностью».
2. Режим работы: «экономный» (короткий код, быстро, меньше расход) или «максимальный» (оформление на пределе возможностей). По умолчанию — «экономный». Подробности — в разделе «Экономия».
3. Размер кадра. По умолчанию — 1920 × 1080.

Потом делай файл строго по разделу «Обязательная разметка». Оформление — на вкус преподавателя: гайд его не ограничивает, а цвета образца в разделе 7 — только пример, копировать их не нужно.

## 1. Обязательная разметка

Это минимум, по которому импорт понимает, где слайды. Без него импорт попробует угадать сам, но результат не гарантирован.

- Один файл .html. Всё внутри: стили, скрипты, картинки (вставлены как `data:`-адреса). Картинки по ссылке на соседний файл (`img/photo.png`) не найдутся.
- В `<head>` — размер кадра: `<meta name="deck" content="1920x1080">`.
- Каждый слайд — один элемент с атрибутом `data-deck-slide`, обычно `<section data-deck-slide>`. Его размер — ровно размер кадра (`width: 1920px; height: 1080px`).
- Всё, что видно на слайде, лежит внутри этого элемента: заголовок, шапка, логотип, номер слайда, подписи, фон. Импорт снимает ровно его — что снаружи, на слайд не попадёт.
- Размеры внутри слайда — в px (или в долях самого слайда). Не в `vw`, `vh` и не от размера окна: слайд не должен зависеть от того, в каком окне его открыли.
- Служебное автора — кнопки листания, панели, переключатели темы, всё, что не должно попасть на слайд, — с атрибутом `data-deck-ui`. Импорт это прячет. Добавлять свои инструменты можно сколько угодно, если они помечены.
- Заметки докладчика — внутри слайда в `<aside data-deck-notes>…</aside>`. Они переносятся к слайду и не видны на нём.
- Слайды могут стоять друг под другом или показываться по одному (остальные спрятаны) — импорт справится с обоими вариантами. Если движок вписывает кадр в окно через `transform: scale(…)`, это тоже можно: масштаб импорт снимет сам.
- Листание стрелками и прочие привычки презентаций не нужны: показ, листание и рисование поверх слайдов у доски свои.

### Размер кадра

Импорт берёт размер из `<meta name="deck">` и делает слайды той же формы. Основа — 16:9.

| Кадр | Размер | Когда |
|---|---|---|
| HD | 1280x720 | лёгкие презентации |
| Full HD | 1920x1080 | по умолчанию |
| 2K | 2560x1440 | много мелких деталей на картинках |
| 4K | 3840x2160 | снимки высокой чёткости |
| 8K | 7680x4320 | можно, но снимок всё равно ужмётся до 4K |
| 4:3 | 1440x1080 | под старые проекторы |
| А4 альбом | 1754x1240 | раздаточные листы |
| А4 книжная | 1240x1754 | листы заданий |
| Квадрат | 1080x1080 | карточки |

Чем больше кадр, тем чётче «Слайды картинками». На перенос «Полностью» размер не влияет: там текст и фигуры векторные. Все кадры 16:9 на доске одного размера — как слайд PowerPoint.

## 2. Ступень 1: «Слайды картинками»

Достаточно обязательной разметки. Оформлять можно как угодно. Что стоит знать:

- Снимок делается в браузере преподавателя, поэтому шрифты из Google Fonts работают. Свои файлы шрифтов — только встроенные в файл.
- Не переносятся: видео, звук, `<iframe>` с чужими сайтами, анимация (снимок — в конечном состоянии).
- Могут выйти не точно: размытие фона (`backdrop-filter`), фильтры (`filter`), режимы наложения (`mix-blend-mode`), маски и вырезы (`mask`, `clip-path`), 3D-повороты. Лучше обойтись без них или проверить результат.
- Тени, градиенты, полупрозрачность, скругления, картинки, SVG, формулы — переносятся.

## 3. Ступень 2: «Полностью»

К обязательной разметке добавь эти правила — тогда каждый элемент станет объектом доски, который можно двигать и править.

- Текст — настоящим текстом в HTML. Не картинкой, не в `<canvas>` и не в `::before` / `::after` (такой текст останется на подложке).
- Один абзац, заголовок, подпись — один элемент (`<h1>`, `<p>`, `<div>`). Внутри можно выделять жирным, курсивом, цветом (`<b>`, `<i>`, `<span style="color:…">`), ставить индексы `<sup>`, `<sub>`.
- Списки — через `<ul>` и `<ol>` с `<li>`: станут списками с маркерами и номерами.
- Таблицы — через `<table>` (`<th>`, `<td>`, можно `colspan` и `rowspan`): станут таблицами доски.
- Фигуры (карточки, плашки, кружки) — блок со сплошной заливкой `background-color` и одинаковой рамкой со всех сторон. Скругление — одинаковое у всех углов. Круг — `border-radius: 50%` у квадрата. Такие станут фигурами доски с текстом внутри.
- Картинки — `<img>` или `<svg>`. Формулы — KaTeX или MathJax (станут картинками) или аккуратный текст с `<sup>` и `<sub>`.
- Не поворачивай элементы с текстом (`transform: rotate`) — повёрнутое останется на подложке.
- Шрифты — из списка ниже. Другой шрифт доска заменит похожим, и строки могут переноситься иначе.

Чем больше эффектов, тем больше уходит в неподвижную подложку и тем меньше остаётся править. Градиенты, тени, узоры, полупрозрачные пятна на фоне — это нормально: они просто станут фоном слайда. Но если на градиенте лежит текст, а фигура сделана из нескольких наложенных слоёв, править выйдет только текст.

Если преподаватель просит сложное оформление и при этом «полностью», скажи ему об этом честно и предложи: либо проще оформление, либо перенос «картинками».

### Анимации по щелчку

Чтобы часть слайда появлялась не сразу, а по щелчку — например, решение по шагам, — пометь её номером шага: `data-deck-step="1"`, `data-deck-step="2"` и так далее.

- Без пометки элемент виден сразу. С пометкой — появляется, когда учитель откроет этот шаг: щелчком, стрелкой или кружком с номером шага.
- Помечать можно любой элемент: абзац, строку решения, картинку, карточку, таблицу. Всё внутри помеченного появляется вместе с ним.
- Один номер у нескольких элементов — они появятся одновременно.
- Работает в обоих видах переноса: «полностью» шаг получает каждый объект внутри помеченного, «картинками» — помеченное станет отдельной картинкой своего шага.
- Своих анимаций (CSS, JavaScript) для этого не нужно: показ шагов делает доска. Анимации самой страницы при импорте не переносятся.

```
<section data-deck-slide>
  <h2>Решите уравнение</h2>
  <p>x<sup>2</sup> = 9</p>
  <p data-deck-step="1">x = 3 или x = −3</p>
  <p data-deck-step="2"><b>Ответ:</b> −3; 3</p>
</section>
```

## 4. Шрифты доски

Эти шрифты доска знает и рисует сама — с ними «Полностью» выглядит один в один:

Unbounded, Montserrat, Inter, Roboto, Open Sans, Manrope, Nunito, Rubik, Comfortaa, Lora, Playfair Display, Caveat, PT Sans, PT Serif, Arial, Times New Roman, Calibri, Cambria, Courier New.

- Начертания: обычное (400) и жирное (700). Полужирное 500–600 станет обычным, 700 и выше — жирным.
- Подключать — как обычно, через Google Fonts (`<link href="https://fonts.googleapis.com/css2?family=…">`) или встроенным файлом.
- Нужен шрифт, которого нет в списке, — напишите нам, добавим.

## 5. Экономия: два режима

Спроси преподавателя, какой режим нужен, и коротко объясни разницу.

Экономный (по умолчанию) — меньше кода, быстрее ответ, меньше расход у нейросети:

- Один небольшой движок и данные слайдов массивом: слайды строит короткая функция из списка `{ заголовок, текст, картинка }`. Тогда для новой темы меняются только данные, а не вёрстка каждого слайда.
- Общие классы и CSS-переменные (`--accent`, `--text`) вместо стилей у каждого элемента.
- Без фреймворков и библиотек (кроме KaTeX для формул, если они нужны).
- Картинки — только нужные, сжатые (WebP или JPEG, по ширине не больше кадра), каждая встроена один раз.
- Без анимаций и эффектов, которые всё равно не переносятся.

Максимальный — оформление на пределе: свои фоны, иллюстрации в SVG, продуманная типографика. Правила разметки те же. Предупреди, что файл выйдет больше, а «полностью» перенесёт не всё оформление.

## 6. Математика

- Дроби — числитель над знаменателем (KaTeX `\frac{a}{b}`), не через косую черту.
- Примеры для решения — столбиком, по одному в строке, с местом справа для решения.
- Степени и индексы — `<sup>` и `<sub>` или KaTeX.

## 7. Образец

Минимальная презентация по этому гайду: три слайда 1920 × 1080, шапка внутри слайда, список, таблица, заметки, своя кнопка листания с пометкой `data-deck-ui`. Повторяй её устройство, а оформление делай своё.

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="deck" content="1920x1080">
<title>Степени · 8 класс</title>
<style>
:root{ --accent:#B4441C; --text:#2B2B2B; --bg:#FFF8EE; --card:#FFFFFF; --line:#E8D9C4; }
*{ box-sizing:border-box; margin:0; padding:0 }
body{ background:#111; font-family:Montserrat, Arial, sans-serif; color:var(--text) }
[data-deck-slide]{ position:relative; width:1920px; height:1080px; margin:0 auto 24px; overflow:hidden;
  background:var(--bg); padding:120px 120px 80px; display:flex; flex-direction:column; gap:32px }
.head{ position:absolute; left:120px; top:40px; font-size:26px; font-weight:700; color:var(--accent) }
h1{ font-size:96px; font-weight:700 }
h2{ font-size:64px; font-weight:700; color:var(--accent) }
p, li{ font-size:40px; line-height:1.4 }
ul{ padding-left:56px }
.card{ background:var(--card); border:2px solid var(--line); border-radius:32px; padding:36px 48px; font-size:40px }
table{ border-collapse:collapse; font-size:36px }
th, td{ border:2px solid var(--line); padding:14px 28px; text-align:center; background:var(--card) }
th{ color:var(--accent) }
.nav{ position:fixed; right:24px; bottom:24px }
</style>
</head>
<body>
<section data-deck-slide>
  <div class="head">Алгебра · 8 класс</div>
  <h1>Степени</h1>
  <p>8 класс · урок 7</p>
  <aside data-deck-notes>Начать с вопроса: что такое a в квадрате?</aside>
</section>
<section data-deck-slide>
  <div class="head">Алгебра · 8 класс</div>
  <h2>Свойства степени</h2>
  <ul>
    <li>a<sup>m</sup> · a<sup>n</sup> = a<sup>m+n</sup></li>
    <li>a<sup>m</sup> : a<sup>n</sup> = a<sup>m−n</sup></li>
    <li>(a<sup>m</sup>)<sup>n</sup> = a<sup>mn</sup></li>
  </ul>
  <div class="card"><b>Запомни:</b> при умножении показатели складываются.</div>
</section>
<section data-deck-slide>
  <div class="head">Алгебра · 8 класс</div>
  <h2>Степени двойки</h2>
  <table>
    <tr><th>n</th><th>1</th><th>2</th><th>3</th><th>4</th></tr>
    <tr><td>2<sup>n</sup></td><td>2</td><td>4</td><td>8</td><td>16</td></tr>
  </table>
  <aside data-deck-notes>Попросить продолжить таблицу до n = 10.</aside>
</section>
<div class="nav" data-deck-ui><button onclick="scrollBy(0, 1104)">▼</button></div>
</body>
</html>
```

## 8. Проверка перед отправкой

- В `<head>` есть `<meta name="deck" content="…">`.
- Каждый слайд — `data-deck-slide`, размер ровно как в метке.
- Всё видимое — внутри слайдов; кнопки и панели — с `data-deck-ui`.
- Один файл, картинки встроены.
- Для «полностью»: текст текстом, списки списками, таблицы таблицами, шрифты из списка.
- Решения и подсказки, которые должны появляться по щелчку, помечены `data-deck-step`.
