# Тренажёры

Интерактивные математические тренажёры и совместные доски онлайн-школы Mathh —
от арифметики в столбик до заданий ОГЭ и ЕГЭ. Учитель и ученик могут работать вместе:
одно задание, общая доска, переходы между тренажёрами — в реальном времени.

Сайт: https://dan-tutor-math.github.io/math-ttrainers/ — каталог на главной
странице [`index.html`](./index.html).

Подробная карта устройства, модель данных и история решений — в
[`HANDOFF.md`](./HANDOFF.md). Его стоит прочитать до любой правки.

## Тренажёры

**Действия с числами**
- [`addition.html`](./addition.html) — сложение в столбик
- [`subtraction.html`](./subtraction.html) — вычитание в столбик
- [`multiplication.html`](./multiplication.html) — умножение в столбик
- [`division.html`](./division.html) — деление в столбик

**Уравнения**
- [`linear.html`](./linear.html) — линейные уравнения
- [`quadratic.html`](./quadratic.html) — квадратные уравнения

**Дроби и степени**
- [`fraction_multiply.html`](./fraction_multiply.html) — умножение дробей
- [`fraction_divide.html`](./fraction_divide.html) — деление дробей
- [`powers.html`](./powers.html) — действия со степенями

**ОГЭ** (часть 1, задания №1–19)
- [`oge1_5.html`](./oge1_5.html) — №1–5. Практические задачи (шины, тарифы…)

- [`oge8.html`](./oge8.html) — №8. Упрощение выражений
- [`oge9.html`](./oge9.html) — №9. Уравнения
- [`oge10.html`](./oge10.html) — №10. Теория вероятности
- [`oge11.html`](./oge11.html) — №11. Графики функций
- [`oge12.html`](./oge12.html) — №12. Вычисления по формуле
- [`oge13.html`](./oge13.html) — №13. Неравенства
- [`oge14.html`](./oge14.html) — №14. Прогрессии

- [`oge19.html`](./oge19.html) — №19. Верные утверждения

В большинстве заданий ОГЭ режимы «Обучение» и «Тренировка» пока заглушки —
полноценно работает «Экзамен».

**ЕГЭ, профильный уровень** — [`ege_prof.html`](./ege_prof.html): все 20 позиций
демоверсии ЕГЭ-2027 на одной странице, номер задания в адресе
(`ege_prof.html?n=7`). Задания, решения и критерии ФИПИ лежат в
[`ege-prof-bank.js`](./ege-prof-bank.js), рисунки — в
[`ege-prof-figs.js`](./ege-prof-figs.js). Работают все три режима: «Обучение»
(идея и решение по шагам), «Тренировка» (задание, поле ответа и кнопка
«Показать решение и ответ») и «Экзамен» (только задание и поле ответа).
Ответ засчитывается по значению, а не по записи: `169/5` и `33,8`, `(1;4]` и
`1 < x ≤ 4` — одно и то же. Как в ОГЭ №8: рядом с заданием можно добавить
ещё несколько («+1…+10»), за пятёрку решённых дают медаль, есть история
решённого, плавающая клавиатура для телефона (во второй части с π и √) и
конспект урока в PDF.

**ЕГЭ, базовый уровень** — [`ege_base.html`](./ege_base.html): все 21 позиция
демоверсии ЕГЭ-2027 базового уровня, 80 прототипов, банк
[`ege-base-bank.js`](./ege-base-bank.js), рисунки
[`ege-base-figs.js`](./ege-base-figs.js). Это та же страница, что у профиля:
руками её не правят, а пересобирают из `ege_prof.html` командой
`python3 sync_ege_pages.py`. Засчитываются все ответы из ключа ФИПИ, в
заданиях на выбор утверждений порядок цифр не важен.

**Доски** — [`boards.html`](./boards.html): бесконечный тетрадный холст, папки,
перенос между компьютерами файлом, общие доски с учеником по приглашению.

## Как устроено

Чистый HTML + CSS + JavaScript, без фреймворков и без шага сборки: файлы
редактируются напрямую, публикация — пуш в `main` (GitHub Pages).

- Каждый тренажёр — одна HTML-страница со своей вёрсткой, стилями и логикой.
  Оформление («Liquid Glass», светлая/тёмная тема) сознательно продублировано
  в каждом файле, чтобы страницы не зависели друг от друга.
- Общее для всех страниц вынесено в модули и подключается `<script src>`:
  совместная сессия (`session-share.js`), доска поверх задания
  (`trainer-board.js`), «+ ещё примеры» (`trainer-multi.js`), «Подборка»
  (`basket-core.js`), история урока в PDF (`lesson-history.js`).
- Совместная работа и общие доски — Supabase (Realtime + Postgres). В клиенте
  только публичный ключ (`supabase-config.js`). Библиотеки (`supabase-js`,
  `jsPDF`, `html2canvas`) лежат в репозитории, а не грузятся с CDN.
- Доски хранятся в браузере (IndexedDB), общие — ещё и на сервере.

Тема по умолчанию следует системной и меняется вживую; явный выбор кнопкой в
углу запоминается.

## Запуск у себя

Нужен любой локальный веб-сервер (с `file://` не заработают модули и хранилище):

```
python3 -m http.server 8000
```

и открыть http://localhost:8000/.

## Тесты

Лежат рядом с кодом, по одному на правку: `test_prompt<номер>_*.py`
(Python + Playwright). Каждый сам поднимает сервер на своём порту:

```
python3 test_prompt54_smoke_all_pages.py
```

`test_prompt54_smoke_all_pages.py` открывает все страницы и ловит ошибки
JavaScript — его стоит прогонять после любой массовой правки, а
`test_prompt55_ege_prof.py` и `test_prompt57_ege_base.py` заодно проверяют весь банк заданий ЕГЭ: эталонные
ответы, формулы и рисунки. Совместный режим
в тестах идёт на заглушке Supabase; живьём его нужно перепроверять на сайте.
