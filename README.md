# Тренажёры

Набор интерактивных математических тренажёров для школьников — от арифметики в столбик
до заданий ОГЭ. Каждый тренажёр — самостоятельный HTML-файл без зависимостей и сборки:
открываешь в браузере (или публикуешь как статику) — и он работает.

Открой [`index.html`](./index.html) — это каталог со ссылками на все тренажёры.

## Тренажёры

**Действия с числами**
- [`addition.html`](./addition.html) — сложение в столбик
- [`subtraction.html`](./subtraction.html) — вычитание в столбик
- [`multiplication.html`](./multiplication.html) — умножение в столбик
- [`division.html`](./division.html) — деление в столбик

**Уравнения**

## Технологии

Чистый HTML + CSS + JavaScript, без фреймворков и без шага сборки. Каждый файл — единое
целое: разметка, стили и логика в одном месте. Общий дизайн ("Liquid Glass") и переключение
светлой/тёмной темы вынесены как переиспользуемый набор CSS-переменных, продублированный
в каждом файле для полной автономности.

Тема сайта по умолчанию следует системной теме браузера и обновляется вживую при её смене;
явный выбор пользователя (кнопка в правом верхнем углу) запоминается и больше не
переопределяется системой.

## Запуск

Зависимостей нет — просто открой `index.html` в браузере. Чтобы выложить как сайт,
достаточно раздать папку любым статическим хостингом (например, GitHub Pages).
